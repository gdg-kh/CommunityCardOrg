# 社群數位簽到護照：2026 年底搶先試玩與公鑰建立指南

本指南專為高雄各社群主辦方撰寫。距離 2027 年正式啟航還有兩個多月，為了讓大家提前熟悉 2027 年全新的「數位簽到護照」功能，我們特別開放 2026 年 10 月至 12 月的實體與線上聚會作為公開試玩期。

各社群主辦方可以在接下來兩個月的真實活動現場，直接投影簽到條碼讓參加者現場打卡試玩。所有在試玩期所收集的測試印章與活動，將於 2027 年正式上線時由管理員手動歸零重新開始。

---

## 一、系統運作機制與優勢

2027 數位簽到護照採用密碼學非對稱加密技術（ECDSA P-256）：
1. 零後端架構：所有簽章與驗證都在靜態網頁與參加者的手機瀏覽器本機完成，無須架設後端資料庫。
2. 隱私安全：不蒐集參加者個資、不需註冊帳號、不依賴第三方平台。
3. 離線可用：參加者手機會自動快取印章資料，離線時亦可開啟護照展示成果。
4. 防偽機制：每一枚印章皆由各社群的專屬私鑰完成數位簽章，無法被偽造或竄改。

## 三、主辦方事前準備：建立社群專屬公鑰（只需執行一次）

若社群尚未在系統中登錄公鑰，參加者現場掃碼時系統會提示該社群尚未開通集章。因此請各社群主辦方在活動前依序完成公鑰建立：

### 步驟一：開啟主辦人管理工具
使用電腦瀏覽器開啟主辦方工具頁面：
https://community-card.org/2027/organizer.html

### 步驟二：產生社群金鑰對
1. 在頁面頂端切換至「金鑰管理」標籤頁。
2. 在社群下拉選單中，選取您的社群名稱。
3. 點選「產生並下載金鑰檔」按鈕。
4. 瀏覽器會自動下載一個 JSON 格式的金鑰檔案，檔案名稱格式為 keypair-社群代號-時間戳記.json。

### 步驟三：妥善保存私鑰檔案
下載的金鑰檔案包含私鑰資訊（含 d 欄位）。請將此檔案妥善保存在主辦團隊的電腦或安全儲存空間中。
切勿將私鑰（含有 d 欄位的檔案）公開或上傳至公開儲存庫。活動現場每次要簽發簽到碼時，都需要載入此金鑰檔。

### 步驟四：提交公鑰發起拉取請求
1. 產生金鑰後，頁面下方會顯示一段「給 stamps.json 的設定片段（只有公鑰，不含私鑰）」。
2. 複製該段 JSON 內容（僅含 kid 與 jwk 的 x、y 座標，不含私鑰 d 欄位）。
3. 前往 GitHub 儲存庫：gdg-kh/CommunityCardOrg。
4. 開啟 2027/stamps.json 檔案，找到您所屬社群的 publicKeys 陣列區塊。
5. 將複製的公鑰 JSON 物件貼入 publicKeys 陣列中。
6. 提交變更並發起拉取請求（Pull Request, PR）。
7. 經管理者審核合併至 main 分支後，您的社群即具備正式簽章打卡資格。

## 四、活動現場實戰：如何讓參加者現場打卡試玩

在公鑰合併生效後，接下來兩個月舉辦聚會時，即可在活動現場讓大家體驗打卡：

### 步驟一：活動當天載入私鑰
1. 在活動現場的投影電腦上開啟 2027/organizer.html。
2. 在「簽到碼簽發」標籤頁，點選「選取金鑰檔」，上傳先前下載的私鑰 JSON 檔案。
3. 系統解析完成後，會顯示綠色提示「已解鎖金鑰，已登錄於 stamps.json」。

### 步驟二：選取活動與投影簽到條碼
1. 系統已同步讀取 2026 與 2027 的活動資料。選單會自動預設選取當天即將舉行的活動名稱與日期。
2. 簽到模式選擇：
   - 實體聚會：使用預設的「一般簽到碼」，有效時間為活動當天 00:00 至隔天 23:59。
   - 防外流或高防護需求：可勾選「輪替模式（rotate）」，條碼每 5 分鐘自動刷新。
   - 混合活動：若同時有現場與線上直播，可選「實體＋線上」，系統會為線上參與者產生專屬條碼。
3. 點選「產生 QR Code」，並將產出的條碼視窗最大化投影在活動大螢幕上。

### 步驟三：引導參加者現場掃碼打卡
1. 請現場參加者拿出智慧型手機，使用相機或條碼掃描器掃描螢幕上的快速回應碼。
2. 掃描後會自動開啟簽到頁面（checkin.html），瀏覽器在數毫秒內完成數位簽章驗證。
3. 畫面顯示打卡成功，並蓋上該場活動專屬的社群印章（包含活動名稱、日期與實體或線上標記）。
4. 點選頁面底部的「查看護照」，即可進入數位護照首頁（passport.html）。

### 步驟四：體驗數位護照各項成果
參加者可以在護照頁面體驗以下完整功能：
1. 集章格子與全年度回顧：點選社群圖示可查看該社群在月曆上的所有場次格子，已簽到的活動會呈現點亮狀態。
2. 專屬印章視覺：依據社群設定，實體與線上簽到可呈現彩色、單色或自訂圖像等不同視覺樣式。
3. 跨社群獎勵兌換提示：若達成社群設定的集章門檻（例如參加指定場次或跨社群參與），系統會自動跳出兌換提示。
4. 護照備份與轉移：在護照底部點選「備份與轉移」，可複製專屬備份代碼或下載文字檔，在其他手機開啟時貼上即可完全還原所有印章。
5. 獨立密碼學驗證頁面：參加者或主辦方可將備份代碼貼入 verify.html，檢驗每一個印章的密碼學簽章與公鑰狀態。

## 五、試玩期常見問題與新社群加入說明

### 問題一：其他外部合作社群想加入數位護照，該如何申請？
在這個平台公開亮相的社群，必須由該社群的組織者知情並主動填表申請。若您的社群希望參與合作，請聯繫高雄社群名牌卡團隊並填寫合作申請表單。經確認並審核後，管理員會將社群資料加入 stamps.json 的 partners 名冊中，屆時即可依本指南建立公鑰並啟用集章。

### 問題二：為什麼要在 2026 年底這兩個月提前試玩？
為了讓各社群主辦方熟悉私鑰簽署流程，並讓常態參與社群的朋友們先體驗手機掃碼與集章護照的介面操作，及早收集意見與調整印章設計。

### 問題三：試玩期間收集的印章，2027 年會保留嗎？
不會。這兩個月為功能體驗與公開測試期，在 2027 年 1 月正式年度開始時，管理員會手動歸零重新開始，讓所有人在 2027 年站在同一起跑線開始全新的年度集章。

### 問題四：掃碼時如果跳出「簽到碼已過期」是甚麼原因？
如果測試的是先前已經結束的歷史聚會，因為超過了當天有效時間，系統會判定過期。若社群需要補蓋過去已結束的活動，請主辦方切換到主辦工具的「過去活動補簽（makeup）」標籤頁，該功能會產生當下 10 分鐘內有效的補簽條碼。若為當天進行中的活動，請直接使用一般簽到碼即可。
